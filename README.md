# Monsters vs. Aliens save/load Coordinates

Cheat Engine table for saving and loading your character's position.

This table targets the ViTALiTY NoCD executable, MD5 31F3...

## Usage

1. Start the game and load a level.
2. Open the `.CT` file in Cheat Engine. (recommended: version 7.6+)
3. Attach Cheat Engine to `Game.exe` and enable the coordinates script.
4. Press **F5** to save your position.
5. Press **F9** to return to the saved position.

There is one temporary save slot. Save again after changing levels or characters. If the game is paused, save/load requests take effect when gameplay resumes. Disable older versions of the coordinates script before enabling this one.
